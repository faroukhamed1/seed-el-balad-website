# Seed El Balad — الموقع الرسمي

موقع ثابت (Static HTML/CSS/JS) — 17 صفحة محتوى + الرئيسية، ثنائي اللغة (عربي/إنجليزي) مع زر تبديل اللغة.

## النشر على Vercel

**الطريقة الأسرع (بدون GitHub):**
1. اعمل حساب على vercel.com (لو معندكش).
2. من الداشبورد → Add New → Project → Deploy without Git.
3. اسحب مجلد الموقع كامل (كل ملفات .html + styles.css + script.js) وارفعه.
4. Vercel هيكتشف إنه موقع Static تلقائيًا وينشره فورًا، وهيديك رابط .vercel.app.
5. تقدر تربط دومين gf-egypt.com من إعدادات المشروع → Domains.

**الطريقة الاحترافية (مع GitHub، أفضل للتحديثات المستقبلية):**
```
cd seed-el-balad-site
git init
git add .
git commit -m "Seed El Balad website"
git remote add origin <رابط الريبو بتاعك على GitHub>
git push -u origin main
```
بعدين من Vercel → Add New → Project → Import من GitHub، واختار الريبو. أي تعديل تعمله وتعمله push هيترفع تلقائيًا.

## نموذج التواصل وطلب الموزع
النموذجين شغالين فعليًا عن طريق **formsubmit.co** (خدمة مجانية بترسل الرسائل لإيميل CEO@gf-egypt.com من غير ما تحتاج سيرفر خلفي).
⚠️ أول رسالة هتتبعت هتوصل كـ "تفعيل" — لازم تفتحها وتضغط confirm عشان الخدمة تشتغل بعد كده تلقائي.

لو حابب حل أكتر احترافية (نموذج مربوط بـ CRM أو قاعدة بيانات) قولّي وأظبطهولك.

## الملفات
- `index.html` — الرئيسية
- 17 صفحة محتوى (عن الشركة، المنتجات، الجملة، الجودة، الأسئلة الشائعة، السياسات... إلخ)
- `styles.css` — نظام التصميم الموحد (الألوان، الخطوط، العناصر)
- `script.js` — تبديل اللغة + قائمة الموبايل
